# Game Console: project notes

ESP32-C3 retro game console. PlatformIO, Arduino framework, TFT_eSPI with ILI9341 (240x320 portrait).

## Build and flash
- Env: `esp32-c3-devkitm-1` (default). Partitions: `huge_app.csv`. Monitor: 115200 baud.
- USB CDC on boot is enabled (`ARDUINO_USB_CDC_ON_BOOT=1`).
- Always build and flash the connected console after firmware changes (user preference).
- Attempt flashing directly without checking port usage first (user preference). Only investigate port usage or serial monitors if the upload fails.
- The user runs interactive/kill commands themselves; ask before killing processes.
- Menu-only preview firmware lives in `menu_preview/` (separate PlatformIO project).

## Hardware pinout
Display (`lib/TFT_eSPI/User_Setups/Setup70c_ESP32_C3_ILI9341.h`):
- CS GPIO4, DC GPIO3, MOSI GPIO2, SCK GPIO1, MISO GPIO21
- Backlight GPIO0 (HIGH = on), RST tied to 3V3 (`TFT_RST -1`)

Other pins (`src/config.h`):
- Right button: D8/GPIO8, active-low (10k pull-up)
- SD card CS: GPIO9
- I2S (MAX98357A): BCLK GPIO6, LRCLK GPIO7, DOUT GPIO5 (from `src/config.h`; the music player uses these)
- I2C: SDA GPIO10, SCL GPIO20
- Buttons (all active-low): ADS1115 A0 = Up, A2 = Down, A3 = Left, A1 = Shoot; D8/GPIO8 = Right.
- ADS1115 is at I2C address 0x48 (`src/buttons.cpp`).

## Code layout
- `src/menu.ino`: home launcher, Settings, Info, Sound screens
- `src/ui_kit.h/.cpp`: shared `ui::` helpers. Use these for every screen.
  - Helpers: `card`, `heading`, `listRow`, `listAll`, `valueRow`, `infoRow`, `stat`, `pill`, `chip`, `hint`, `pauseSheet`, `pauseItem`, `gameOverSheet`, `startCard`, `inkOn`
  - Colors: `CARD`, `GROUP`, `SEPARATOR`, `LABEL`, `SECONDARY`, `INK_DARK`
- Games: `src/snake.ino`, `tetris.ino`, `breakout.ino`, `run.ino`, `galaga.ino`, `sliding_puzzle.ino`, `mini_games.ino`, `life.cpp`, `mandelbrot.cpp`
- `src/game.ino`: high-score screen, countdown, I2S tone task (`setBuzzerTone`)
- `src/video_player.cpp`: Videos app (playlist of `/videos/<name>/` with video.mjpeg + audio.wav + info.txt from `tools/yt_to_console.py`). Shares the music player's global `JPEGDEC jpeg`.
- RAM: large buffers are heap-allocated only while their app runs (music PNG/MP3/read buffer, Life board, video buffers). Keep new big buffers off static RAM.
- `src/music_player.cpp` lives in `menu_preview/src/`. The port from `display_test/` is the reference.
- Icons: `src/home_icons.h` is generated by `tools/make_icons.py` (52x52 RGB565).

## UI conventions
- Sentence-case labels, one card colour, no decorative stripes or stacked borders.
- Font: the built-in fonts 2 and 4 only. Avoid characters such as "·" that the font can't draw.
- Keep screens within the pause sheet area (18,58)-(222,258) when a countdown repaints only that region.
- Consistent button mapping across all games: see the `startCard` controls list.

## Known open issues
- Display: the new pin map was applied; the user has not yet confirmed the panel shows the new UI.
- SD card: works now (user confirmed 2026-11-14). The earlier "Card Failed" at boot is resolved.
- Audio: I2S driver is reinstalled per track (`i2s_driver_uninstall(I2S_NUM_0)` before `mp3.begin`). No confirmed sound yet. Check VIN (5 V), SD pin, BCLK/LRC/DIN wiring, and speaker terminals.
- New game UIs have not been checked on the device.
